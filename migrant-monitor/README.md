# Монитор мигрантов

PWA приложение для отслеживания сроков документов мигрантов с интеграцией WhatsApp/Telegram.

## 🚀 Возможности

- **PWA** - устанавливается как нативное приложение на телефон
- **Офлайн работа** - кеширование ключевых экранов
- **Роли пользователей** - Owner, HR Admin, HR, Manager, Employee
- **Инлайн редактирование** - даты и комментарии прямо в карточках
- **Интеграция** - WhatsApp, Telegram, звонки
- **Автоматические уведомления** - просроченные и истекающие документы
- **Темная/светлая тема** - адаптивный дизайн
- **Mobile-first** - оптимизировано для мобильных устройств

## 📱 Установка и запуск

### Требования
- Node.js 18+
- npm или yarn

### Установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd migrant-monitor

# Установка зависимостей
npm install

# Настройка базы данных
npx prisma generate
npx prisma db push

# Создание тестовых данных
node scripts/seed-database.js

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

### Сборка для продакшена
```bash
npm run build
npm start
```

## 👤 Тестовые пользователи

После выполнения `node scripts/seed-database.js` будут созданы следующие пользователи:

| Email | Пароль | Роль |
|-------|--------|------|
| owner@company.com | admin123 | Owner |
| hr-admin@company.com | hr123 | HR Admin |
| hr@company.com | hr123 | HR |
| manager@company.com | manager123 | Manager |

## 📋 Функциональность

### Главный экран
- Список сотрудников с карточками
- Вкладки "Активные" / "Отправленные"
- Фильтр "только просроченные или 7 дней"
- Переключатель темы
- Кнопка добавления сотрудника

### Карточка сотрудника
- **ФИО** (жирным шрифтом)
- **Телефон** с форматированием
- **Даты документов** с цветовой индикацией:
  - 🔴 Красный - просрочено
  - 🟡 Желтый - истекает в течение 30 дней
  - ⚪ Обычный - в порядке
- **Комментарий** с инлайн редактированием
- **Кнопки действий**:
  - WhatsApp (с автосообщением)
  - Telegram
  - Позвонить
  - Отправлено/Отменить

### Автосообщение WhatsApp
Формат: "Здравствуйте, [Имя Отчество]! [Список проблем]. Пожалуйста, пришлите сканы."

Пример: "Здравствуйте, Иван Иванович! Патент истекает 12.10.2025, Регистрация просрочена 01.09.2025. Пожалуйста, пришлите сканы."

### Права доступа

| Роль | Права |
|------|-------|
| Owner | Полный доступ ко всему |
| HR Admin | Все модули и настройки |
| HR | Сотрудники, документы, задачи/отчёты |
| Manager | Просмотр своего отдела, создание задач, отметка "Отправлено" |
| Employee | Только свой профиль (в будущем) |

## 🛠 Технологии

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: SQLite + Prisma ORM
- **Auth**: NextAuth.js
- **PWA**: Service Worker, Web App Manifest
- **UI**: Radix UI, Lucide Icons
- **Forms**: React Hook Form + Zod

## 🔄 Логика работы

### Статусы документов
- **Просрочено** - дата < сегодня (красный)
- **Скоро истекает** - дата в диапазоне 0-30 дней (желтый)
- **Критически срочно** - просрочено или ≤7 дней

### Автонумерация
Номера сотрудников пересчитываются автоматически при наличии ФИО.

### Нормализация телефонов
- Хранение: только цифры
- Отображение: +7 (900) 123-45-67
- Валидация: минимум 10 цифр для активации кнопок

### Audit Log
Все изменения записываются в журнал аудита с указанием:
- Кто изменил
- Что изменил
- Старое/новое значение
- Время изменения
