# Монитор мигрантов

Локальное PWA приложение для отслеживания сроков документов мигрантов с интеграцией WhatsApp/Telegram и файловыми загрузками.

## 🚀 Быстрый старт

```bash
# Клонирование и установка
git clone <repository-url>
cd migrant-monitor
npm i

# Настройка базы данных
npx prisma db push

# Создание тестовых данных (опционально)
node scripts/seed.js

# Запуск приложения
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

## 📋 Доступные команды

```bash
npm i                 # Установка зависимостей
npx prisma db push    # Создание/обновление БД
npm run dev          # Запуск в режиме разработки
npm run build        # Сборка для продакшена
npm start            # Запуск продакшен сборки
npm run test         # Запуск unit-тестов
npm run test:ui      # Запуск тестов с UI
npm run test:run     # Одноразовый запуск тестов
```

## 🛠 Технологии

- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS
- **UI**: shadcn/ui компоненты (Radix UI)
- **Backend**: Next.js API Routes
- **Database**: SQLite + Prisma ORM
- **File Storage**: Локальная файловая система
- **Testing**: Vitest + Testing Library
- **PWA**: Service Worker, Web App Manifest

## 📁 Структура данных

### Модели базы данных:

**Employee** - Сотрудники
- `fullName` - ФИО
- `phone` - Телефон (только цифры)
- `department` - Отдел/Локация
- `comment` - Комментарий
- `sent` - Статус отправки уведомления
- `patentDate, registrationDate, passportDate, checkDate` - Даты документов

**Document** - Файлы документов
- `employeeId` - Связь с сотрудником
- `type` - Тип документа (passport/patent/registration/check/other)
- `fileName` - Оригинальное имя файла
- `mimeType` - MIME тип
- `size` - Размер в байтах
- `storedAt` - Путь к файлу в ФС

**Settings** - Настройки приложения
- `urgentDaysDefault` - Пороги срочности по умолчанию (7 дней)
- `warnDaysDefault` - Пороги предупреждений (30 дней)
- `perFieldOverrides` - Переопределения порогов по типам документов
- `whatsappTemplate` - Шаблон сообщения WhatsApp

## 🔧 Конфигурация

Создайте файл `.env` на основе `.env.example`:

```bash
# Database
DATABASE_URL="file:./prisma/dev.db"

# File Upload Settings
UPLOAD_DIR="./uploads"
MAX_FILE_SIZE=10485760  # 10MB in bytes
ALLOWED_FILE_TYPES="image/jpeg,image/png,image/webp,application/pdf"
```

## 📱 Функциональность

### Дэшборд
- **Статистические карты** - всего сотрудников, требуют внимания, отправлены
- **Фильтр срочности** - показать только просроченные или срочные (≤7 дней)
- **Переключатель темы** - светлая/темная/системная
- **Кнопка настроек** - редактирование порогов срочности

### Карточки сотрудников
- **Автонумерация** - порядковые номера
- **ФИО жирным** шрифтом
- **Цветовая индикация дат**:
  - 🔴 Красный - просрочено
  - 🟠 Оранжевый - срочно (≤ порога срочности)
  - 🟡 Желтый - предупреждение (≤ порога предупреждения)
  - 🟢 Зеленый - в порядке
- **Инлайн-редактирование** дат и комментариев
- **Управление документами** - загрузка, просмотр, скачивание, удаление
- **Интеграция** - WhatsApp, Telegram, звонки
- **Статус отправки** - отправлено/активно

### Загрузка файлов
- **Локальное хранение** в `./uploads/<employeeId>/`
- **Поддерживаемые форматы**: JPG, PNG, WebP, PDF
- **Ограничения**: до 10MB на файл
- **Организация по типам**: Паспорт, Патент, Регистрация, Чек, Другое
- **Drag & Drop** интерфейс
- **Превью и скачивание** файлов

### Настройки срочности
- **Общие пороги** - срочно (7 дней), предупреждение (30 дней)
- **Индивидуальные настройки** по типам документов
- **Шаблон WhatsApp** с переменными `{name}` и `{problems}`
- **Предпросмотр** итогового сообщения

### WhatsApp интеграция
- **Автогенерация сообщений** на основе шаблона
- **Умное обращение** - по имени+отчеству (если ≥3 слова в ФИО)
- **Список проблем** с датами и типами документов
- **Deep-links** для прямого перехода в WhatsApp/Telegram

## 🎯 Особенности реализации

### Локальность
- **Без внешних сервисов** - никаких Google, Supabase, облачных API
- **SQLite база данных** - один файл `prisma/dev.db`
- **Файловое хранилище** - локальная папка `uploads/`
- **Автономная работа** - все работает офлайн

### Настраиваемость
- **Редактируемые пороги** срочности через UI
- **Per-field настройки** - разные пороги для разных документов
- **Кастомные шаблоны** WhatsApp сообщений
- **Гибкая логика** - легко изменить через интерфейс

### Качество кода
- **TypeScript** строгая типизация
- **Unit-тесты** критической логики
- **Zod валидация** форм и API
- **ESLint/Prettier** форматирование
- **shadcn/ui** консистентный дизайн

## 🐛 Отладка

```bash

chmod 755 uploads

cat .env
```

```bash
# Пересоздание БД
npx prisma db push --force-reset

```

### Проблемы сборки
```bash

rm -rf .next

```
